# Differential tests against the C library

Copyright (C) 2026 tickettoaster GmbH. LGPL 2.1 or later.

The scripts in this directory compare konto_check_ruby with the original C
library. They need a small reference driver built from the C sources of
konto_check 6.15 (https://sourceforge.net/projects/kontocheck/, file
`konto_check-6.15.zip`, LGPL):

```
unzip konto_check-6.15.zip
cd konto_check-6.15
cc -O2 -w -DDEBUG=1 -o kc_ref ../tools/kc_ref.c konto_check.c -lz
```

`kc_ref.c` reads commands from stdin (see its header comment) and prints the
results of the C functions.

```
# all check digit methods 00..E4 with sub-methods, random account numbers
ruby tools/difftest_methods.rb PATH/kc_ref 0-144 1000

# IBAN rules, IBAN generation, kto_check_regel for all banks with a rule
ruby tools/difftest_iban.rb PATH/kc_ref test/fixtures/blz.lut2f 30 1 PATH/konto_check.c

# all bank lookups (lut_* functions) for every BLZ and branch
ruby tools/difftest_lookup.rb PATH/kc_ref test/fixtures/blz.lut2f
# ... C reading a LUT file generated by Ruby, Ruby reading the Bundesbank file
ruby tools/difftest_lookup.rb PATH/kc_ref generated.lut2 blz.txt
```

Known deviation reported by `difftest_lookup.rb`: for a branch index beyond
the number of branches of a bank with IBAN rule 31..35 the C function
`lut_bic()` returns `OK_INVALID_FOR_IBAN` instead of
`LUT2_INDEX_OUT_OF_RANGE`; it evaluates the rule with an unterminated dummy
account buffer (undefined behaviour), the Ruby port returns
`LUT2_INDEX_OUT_OF_RANGE`. All lookups with valid branch indexes agree.

`PORTING_SPEC.md` and `IBAN_PORTING_SPEC.md` describe how the C code was
translated (macros, fall-through, string vs. digit semantics).
